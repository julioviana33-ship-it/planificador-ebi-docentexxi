# 🌟 Planificador EBI Inteligente - DocenteXXI

**"Ideas que brillan, aulas que inspiran"**

## ¿Qué es?

Planificador EBI Inteligente es una aplicación web que ayuda a docentes a diseñar secuencias didácticas completas y alineadas a los marcos de la Educación Básica Integrada (EBI) a partir de una simple idea de clase.

## ✨ Características Principales

✅ **Configuración Flexible:**
- Selecciona el Tramo EBI (Inicial a Secundaria)
- Elige el Espacio del Conocimiento (Científico-Matemático, Comunicación, Artes, etc.)
- Especifica la Unidad Curricular dinámicamente
- Define el Enfoque Metodológico (ABP, Indagación, Gamificación, Cooperativo)

✅ **Generación Automática:**
- Meta de aprendizaje personalizada
- Competencias alineadas al marco curricular
- Criterios de evaluación claros
- Secuencia didáctica completa (Inicio → Desarrollo → Cierre)
- Evaluación formativa (Exit Ticket)

✅ **Exportación:**
- Descarga en Markdown (gratis)
- Descarga en Word editable (.docx) mediante Premium

## 🚀 Cómo usar

### Online (Recomendado)
Visita: [Planificador EBI en Streamlit Cloud](https://planificador-ebi-docentexxi.streamlit.app)

### Localmente

1. **Instala Python 3.8+**

2. **Clona el repositorio:**
   ```bash
   git clone https://github.com/julioviana33-ship-it/planificador-ebi-docentexxi.git
   cd planificador-ebi-docentexxi
   ```

3. **Instala las dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Ejecuta la app:**
   ```bash
   streamlit run app.py
   ```

5. **Abre en tu navegador:**
   ```
   http://localhost:8501
   ```

## 🔧 Enfoques Metodológicos

- **Aprendizaje Basado en Proyectos (ABP):** Resolución de problemas mediante proyectos colaborativos
- **Indagación Científica:** Experimentación y formulación de hipótesis
- **Gamificación Educativa:** Aprendizaje mediante dinámicas lúdicas
- **Aprendizaje Cooperativo:** Trabajo en equipos con roles específicos
